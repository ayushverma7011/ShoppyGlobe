# ShoppyGlobe
ShoppyGlobe is a premium E-commerce platform built with the modern React ecosystem. It provides a seamless shopping experience with real-time API integration, global state management, and a sleek, responsive UI.

# Key Features

1. Real-time Product Discovery: Dynamic fetching from the DummyJSON API.

2. Centralized State Management: Full cart lifecycle (Add/Remove/Update) managed via Redux Toolkit.

3. Instant Search: Client-side filtering for immediate product lookup.

4. Responsive Design: Mobile-first approach using Tailwind CSS.

5. Optimized Routing: Smooth transitions and lazy-loaded components using React Router v6.

##  Installation Guide

1. Clone the repo: `git clone <your-url>`

2. Install: `npm install`

3. Run: `npm run dev`
